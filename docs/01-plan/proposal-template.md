## 5. 개발 계획 — Pleos Connect 구현 방법, 개발 범위, SDK/API 사용 계획

### 5-1. 구현 구조
- Android(Kotlin, Jetpack Compose), minSdk 28, Pleos Connect Emulator 2.1.0에서 검증
- 주행 규제: AAOS `CarUxRestrictionsManager`로 주행 중 화면 자동 전환 (DO 선언)
- 순수 로직은 별도 모듈로 분리해 단위 테스트 (에뮬레이터 없이 검증)
- (그림 1장: 차량 신호 → 앱 로직 → 음성/화면) — [architecture.md](../04-dev/architecture.md)의 그림을 다듬어 사용

### 5-2. SDK/API 사용 계획 (심사 "기술 활용성"의 핵심 — 표로 구체적으로)

| 기능 | SDK | API | 권한 | 제공 상태 |
|---|---|---|---|---|
| 예) 출발·도착 감지 | AAOS Car API | `CarUxRestrictionsManager`, `GEAR_SELECTION` | `CAR_POWERTRAIN` | 사용 가능 |
| 예) 주행거리 기록 | Vehicle | `Odometer.getTripCurrentDrivingDistance` | `CAR_DRIVE` | 사용 가능 |
| 예) 음성 안내 | TextToSpeech | `speak()` (on-device) | `TTS_SERVICE` | 온디바이스 사용 가능 |
| 예) 음성 응답 | SpeechToText | `request()` → `onUpdated()` | `STT_SERVICE` | 온디바이스 사용 가능 |
| 예) 경유지 추가 | NaviHelper | `addWaypoint` / `requestRoute` | `NAVI_ROUTE_SEARCH` | 사용 가능 |
| (확장) 음성 명령 | Gleo Interface | App Schema + Action/Callback | — | 스키마 승인 필요 |
