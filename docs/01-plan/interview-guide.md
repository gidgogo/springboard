# 사용자 인터뷰 가이드 (15분)

기획서 2번(기획 배경)과 6번(사업성)에 **근거**를 넣기 위한 짧은 인터뷰다.
아이디어 확정 전(11-06)에 3~5명, 확정 후(11-09까지) 같은 사람에게 화면 시안을 보여 주며 2~3명.

## 대상

- 운전자 3명 이상 (출퇴근 / 가족 이동 / 업무 이동처럼 이동 패턴이 다른 사람)
- 동승자 2명 이상 (뒷좌석 탑승이 잦은 사람, 아이를 태우는 부모 등)
- 가능하면 신형 차량(인포테인먼트 화면이 큰 차) 운전자 1명

## 진행

1. 목적 설명 (1분): "차 안에서 불편한 점을 듣고 앱 아이디어를 다듬으려 합니다. 이름은 어디에도 쓰지 않습니다."
2. 녹음·메모 동의를 받는다. 기획서에는 **"30대 출퇴근 운전자 A"처럼 익명**으로만 쓴다.
3. 질문 (10분) — **최근 실제 장면**을 묻는다. "~하면 쓰겠어요?" 같은 가정 질문은 마지막에만.

| # | 질문 | 듣고 싶은 것 |
|---|---|---|
| 1 | 최근 일주일 동안 차를 탄 이동 중 가장 기억나는 이동은? | 장면 (누구와, 어디로, 얼마나) |
| 2 | 그 이동에서 짜증 나거나 귀찮았던 순간은? | 불편의 순간 |
| 3 | 그때 어떻게 했어요? 폰·내비·사람으로 해결했나요? | 지금의 대처와 한계 |
| 4 | 그런 일이 얼마나 자주 있나요? | 빈도 (Retention 근거) |
| 5 | 운전 중에 화면을 만지거나 음성으로 무언가 시켜 본 적이 있나요? 어땠나요? | 음성·화면 사용 습관 |
| 6 | 차가 멈춰 있을 때(충전·대기·주차) 차 안에서 주로 뭘 하나요? | 정차 중 시간 |
| 7 | (동승자) 운전자에게 말하기 애매했던 것이 있나요? | 동승자 니즈 |
| 8 | (아이디어 확정 후) 이 화면/장면을 보면 언제 쓰고 싶나요? 안 쓸 것 같은 이유는? | 반응, 반대 의견 |
| 9 | 이게 해결된다면 돈을 내거나 다른 앱을 지울 만한가요? | 지불·전환 의향 (사업성) |

4. 마무리 (1분): 감사, 결과물을 보여 줄지 묻기.

## 정리 틀 (인터뷰 1명당 1줄)

| 응답자 | 장면 | 불편 | 지금 대처 | 빈도 | 강도(1~5) | 인용 한 문장 |
|---|---|---|---|---|---|---|
| A (30대, 출퇴근) | | | | 주 5회 | | "" |

- 3명 이상이 같은 불편을 말하면 기획서 2번 근거로 쓴다 ("인터뷰 5명 중 4명이 …").
- 빈도·강도가 높은 불편이 [idea-selection.md](idea-selection.md) 채점표의 "창의성·사업성" 점수 근거가 된다.

## 주의

- 녹음 파일·실명·연락처는 **저장소에 올리지 않는다** (공개 저장소, 블라인드 심사).
- 유도 질문 금지: "이런 앱 있으면 좋겠죠?" → "그때 어떻게 했어요?"
- 운전 중인 사람에게 인터뷰하지 않는다.
