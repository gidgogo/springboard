# 차량 앱에 쓸 만한 공공 데이터 · API

> NaviHelper에는 장소 검색 API가 없다. 충전소·휴게소·주유소·관광지 같은 장소 정보가 필요하면 아래 공공 데이터를 쓴다.
> 2026-11-05 검색으로 확인한 페이지다. **신청 전 각 페이지에서 제공 항목·트래픽 한도·이용 조건을 다시 확인**한다.

## 2. 쓰기 전에 확인할 것

- **공모전 규정**: 외부 서버·공공 API 사용 범위를 설명회·FAQ로 확인한다 ([contest-overview.md](../00-contest/contest-overview.md) 13절).
- **출처 표시**: 공공누리 유형(1~4유형)에 따라 출처 표시·상업적 이용·변경 허용이 다르다. 앱 안 "정보" 화면과 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)에 출처를 적는다.
- **키 관리**: 인증키는 저장소에 커밋하지 않는다 → [review-and-security.md](../02-pleos/review-and-security.md) 4절.
- **차량 네트워크는 끊긴다**: 시연은 오프라인에서도 되게. 미리 받은 스냅숏을 `assets/`에 넣어 두고, 온라인이면 갱신하는 구조가 안전하다.
- **시연 재현성**: 2차 PT 현장 네트워크를 믿지 않는다. 시연 장면에 필요한 데이터는 앱에 묶어 둔다.
- **좌표계**: 공공 데이터는 WGS84 위경도, 기상청은 격자 좌표, 일부는 TM 좌표 — 변환 필요 여부 확인. NaviHelper 3.0.5는 (위도, 경도) 순서.
